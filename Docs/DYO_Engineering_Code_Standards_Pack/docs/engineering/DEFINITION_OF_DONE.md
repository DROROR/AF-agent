# Definition of Done

A task is done only when applicable items pass:

- [ ] Requirement implemented.
- [ ] Architecture boundaries respected.
- [ ] No unexplained TypeScript errors or unsafe `any`.
- [ ] Runtime inputs validated.
- [ ] Error cases handled.
- [ ] Production logs/events sufficient.
- [ ] Meaningful tests added.
- [ ] Existing tests pass.
- [ ] Lint/typecheck pass.
- [ ] Build passes.
- [ ] Migration included if needed.
- [ ] `.env.example` updated if needed.
- [ ] Documentation updated.
- [ ] No secrets committed.
- [ ] Original `.aep` cannot be overwritten.
- [ ] Recovery considered for AE/external work.
- [ ] Reviewer can understand the change without reverse engineering it.
